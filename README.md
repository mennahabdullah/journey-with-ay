# journey-with-ay

# Describtion
A website that helps kids to learn about Ancient Egypt by reading stories and answering questions. Ay is the explorer cat that guide the user throught their journey. 

# Features
The kids can learn more about Ancient Egyptian Pharaohs, Queens, Battles, Artifacts, and Myths.
The kid earn a badge after finishing a story, and points after answering the questions correctly.
Parents can see their kids' progress and review their answers over the critical thinking questions.

# AI Usage
AI helped wifth generating pictures, writing stories, making sure the information is accurate, and I used it in small parts of the JavaScript code.
